# フェアドロー

抽選の結果を、誰でも再計算できる形で公開するための静的サイト（サーバーなし・個人データは端末の外に出ません）。

1. `index.html` を開く → 「抽選を作る」で乱数の約束（コミットメント）を作り、告知文をコピーして公開する。
2. 締切後に申込CSV（またはリスト）を読み込んで抽選し、結果発表文と `verify.json` を公開する。
3. 誰でも `verify.html` に `verify.json`（または投稿文）を貼れば、同じ結果を再計算して確認できる。

アルゴリズム: fairdraw/2（fairdraw/1 は検証のみ対応）。詳細は `index.html` の「仕組み」を参照。
